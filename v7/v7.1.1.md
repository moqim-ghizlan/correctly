## 1. Goal

The worker can send **one image + instruction** to Gemini or OpenAI under a
new task kind `ocr`, and validate the answer. Proven by tests with a fake
`fetch`. **No visible UI, no capture, no new message.**

## 3. Scope

- `transport.ts`: optional `TaskRequest.image` `{ mimeType, data }` (base64,
  bounded, e.g. ≤ 4 MB of base64); doc comment.
- `gemini-client.ts`: adds the inline image part **after** the text part when
  `image` is set; unchanged body otherwise.
- `openai-client.ts`: adds an `input_image` item (data URL) with the user
  content when `image` is set; unchanged body otherwise.
- `shared/models.ts`: `ModelInfo.vision: boolean`, set for every reviewed
  model from the spike (dated comment); helper `readsImages(provider, id)`
  (unknown → false).
- `TASKS` += `'ocr'`, `SLOT_LABELS.ocr`; quota labels and default caps for
  `ocr` with a migration of stored rules (copy the `withRealtimeCaps`
  pattern); statistics label; fr/en labels where task names are shown.
- `shared/ocr.ts` (pure): result type, `parseOcrAnswer()` (exact fields,
  bound `MAX_SUMMARY_CODE_POINTS`, control characters, `found:false` →
  no-text result).
- `background/ocr.ts`: `ocrTask()` (fixed English instruction, schema
  `{ text, found }`, temperature 0, output budget), `OCR_TIMEOUT_MS`,
  `parseOcr()` — same shape as `background/summary.ts`.
- `shared/errors.ts`: new codes from `v7.1.md` §5 + fr/en texts
  (`COMMON.error`).
- Controller: a method `extractText(image, origin)` **not yet reachable from
  any message**: consent, route slot `ocr`, `readsImages` check
  (`MODEL_NO_VISION` before `admit`), `admit`, `dispatch`, one call with
  `OCR_TIMEOUT_MS`, parse. Covered by tests only.

## 4. Out of scope

Overlay, capture, crop, `EXTRACT_TEXT` message, window button, consent
dialog, settings UI (except labels that tests of existing pages require).

## 5. Tests

O1–O5 (`v7.1.md` §10), plus: controller `extractText` order (vision check
before `admit`; no `fetch` on refusal), timeout uses `OCR_TIMEOUT_MS`, quota
migration with and without existing rules, existing snapshot tests of
correction/rewrite/translate/summary bodies unchanged.

## 6. Pitfalls specific to this part

- Do not change existing request bodies (pitfall 6).
- Do not guess field names: copy them from the docs found in the spike and
  cite them.
- An IndexedDB schema bump only if needed; if done, test old → new.
- The task `ocr` appears automatically in `ROUTE_SLOTS` → check the settings
  page tests (providers, limits, stats) and update their expectations, not
  their logic.
