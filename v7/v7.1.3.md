## 1. Goal

The feature works end to end in the browser with the owner's key: Capture
text button → area → one `ocr` request → text in the window → the four tabs.
Still **no version change and no website**.

## 2. Scope

- **Message** `correctly.v5.extractText` (`shared/contracts.ts` constant +
  `isExtractTextRequest` exact-shape guard, `v7.1.md` §6); accepted only
  from a content-script sender with `sender.tab` in `background/index.ts`.
- **Worker:** handler = guard → controller `extractText` order from
  `v7.1.md` §4: consent → `ocr.consent` → route `ocr` → `readsImages` →
  `admit` → `captureArea` (part 2) → `dispatch` → one call → parse → reply
  `{ ok, text, found, operationId, quota }` or `{ ok:false, code }`.
  Capture failure after `admit` and before `dispatch` = not counted.
- **Settings:** `correctly.v5.settings.ocr.consent` (normalized, default
  false, excluded from sync and from the Firebase backup domains — check
  `shared/sync.ts` / `background/domains.ts`); `pageConfig()` exposes only
  `ocrConsent: boolean` if the window needs it.
- **Window** (`content/modal.ts`):
  - icon button "Capture text" at the end of the tab bar (D2), fr/en
    tooltip and `aria-label`, disabled while any request is in flight;
  - click: if the shared box holds typed text → confirmation (D3); if no
    image consent → consent dialog (D5) and, on Accept, a message to the
    worker that sets `ocr.consent` (trusted path only — the page never
    writes storage directly: reuse how text consent is granted);
  - hide window + handle (+ selection button) → `selectArea` → on `null`,
    show the window again, nothing sent → else `EXTRACT_TEXT` → show the
    window with a loading state → on success, `setText(text)` and switch the
    source to copy-only (notice "Text read from an image — copy only");
    on `found:false`, message "No text found"; on error, `COMMON.error`;
  - focus returns to the button after the flow; Esc in the window still
    closes it as before.
- **Settings page:** route slot "Text from image" appears in AI providers with
  a warning when the selected model cannot read images; limits and
  statistics pages list `ocr`; "Reset image consent" in Privacy; static texts
  through `scripts/i18n-options.mjs` + `npm run format`.
- **Browser smoke test** (`scripts/verify-browser.mjs`): add a step with a
  stub provider if the script supports stubs (else document NOT TESTED and
  why).

## 5. Pitfalls specific to this part

- The page must never write `storage.local` (only trusted contexts do):
  consent goes through a worker message.
- The window may have been opened on a live field: after OCR, Apply must be
  impossible (source copy-only), and Undo of a previous Apply untouched.
- Show the window again on **every** path (cancel, error, timeout), or the
  user loses it.
- Ensure `selectArea` cannot start twice (double click).
- `sharedText` limit: the box accepts up to `MAX_SUMMARY_CODE_POINTS`;
  existing per-tab "too long" messages must still appear for the 2,000 tabs.
- Opening paths: handle (`smart.js`) and `content.js` both bundle the modal —
  test both bundles build and contain the button.
