# Todos

- [x] **Capturer du texte : afficher le résultat dans un nouveau modal dédié.**
      Aujourd'hui le texte scanné (bouton « Capturer du texte », à droite de la
      barre d'onglets) s'affiche dans la modale connue (Correction / Reformulation /
      Traduction / Résumé), ce qui n'est pas logique. Trouver une solution : une
      modale séparée pour le résultat du scan (copie seule, comme prévu en V7.1).

- [x] **Correction en direct : option « corriger à la fin de l'écriture ».**
      Dans Paramètres → Correction en direct, ajouter un mode où la vérification
      n'part qu'une fois que l'utilisateur a fini d'écrire (pas à chaque mot ni à
      chaque phrase). Raison : trop de requêtes, environ 1,4 € en une journée.

- [x] **Reformulation : conserver les retours à la ligne.**
      Quand le texte à reformuler contient des retours à la ligne, la sortie du
      modèle est toujours sans retour à la ligne (tout sur un seul bloc). Garder la
      structure en paragraphes/lignes du texte d'origine.
