# Correctly V6.1.3 — Underlines and card (first usable version)

**Parent spec:** `v6/v6.1.md`. **Part 3 of 4.** Requires V6.1.2.
**Status:** CODE DELIVERED (overlay, card, Replace/Copy, settings page,
tests R4, R8, R10). Manual check on a plain textarea and Gmail compose NOT DONE.

## 1. Goal

First end-to-end version: with the user's key in API mode, mistakes are
underlined while typing and fixed in one click. Nothing is ever changed
without the click.

## 2. Scope

- **WP4 overlay and card** in `smart.js` (opt-in `triggers.realtime`):
  - eligible fields: textarea, text inputs, simple `contenteditable`; same
    exclusions as V5.2 plus `autocomplete` hints, `aria-hidden`/`inert`/
    disabled/read-only, code editors, Correctly's own UI (R4);
  - overlay in a **closed shadow root**, positioned from
    `Range.getClientRects()` (contenteditable) or a mirror element
    (textarea/input); repositioned on scroll/resize/input with
    `requestAnimationFrame` and passive listeners; removed on blur or
    navigation; **no DOM change inside the field** (R10);
  - red wavy = spelling, blue = grammar; light/dark aware; never covering
    the caret;
  - hover/focus card: suggestions, one-line reason, **Replace**; keyboard:
    Alt+Shift+↓ next mistake, Enter replaces, Esc closes;
  - **Replace** re-reads the field, checks the range still holds `original`,
    replaces through the existing V5 path with input events; otherwise
    "outdated" and recheck; where V5 Apply is not allowed (rich editors):
    "Copy suggestion" (R8).
- **Minimal settings page** "Real-time correction" (fr/en): switch (asks
  all-sites access only when turned on), engine = API, **consent dialog**
  that sets `apiConsent` (warning: everything typed in checked fields is
  sent to the provider), route selection.

## 3. Out of scope

Local engine, Ignore, dictionary, site list, badge, Auto mode.

## 4. Tests

R4, R8, R10 plus a jsdom flow with a stub engine: type → pause → underline →
Replace. Strings in `content/messages.ts` and `options/messages.ts`
(static texts via `scripts/i18n-options.mjs`, then `npm run format`).
