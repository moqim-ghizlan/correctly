## 1. Product decision and acceptance contract

### 1.1 Mission

Underline spelling and grammar mistakes **while the user types** in any
page, like a real-time grammar checker, and let them fix a word in one
click. Nothing is ever changed without that click.

### 1.2 User flow

1. The user types in a text field on any site.
2. After a **pause** (~1 s without typing) or at the **end of a sentence**
   (`.` `!` `?` `…` or a line break), Correctly checks **the sentence that
   changed** (with the previous sentence as context). Never word by word: a
   word alone hides grammar errors ("les chat mange") and would multiply
   requests.
3. Mistakes are **underlined** under the exact words: red wavy = spelling,
   blue = grammar, grey dotted = punctuation/style (optional, D5).
4. **Hover** (or keyboard focus) on an underlined word → a small card: the
   suggestion(s), a one-line reason, buttons **Replace**, **Ignore**, **Add
   to dictionary**.
5. **Replace** changes exactly that word/range if the text there is still
   the same; otherwise the card says it is outdated and the word is checked
   again.
6. Underlines move with the text and disappear as soon as the user edits
   the underlined word.

### 1.3 Engines (owner decision D1)

| Engine                     | Where it runs                                                                                  | Cost                              | Text leaves the PC?             | Availability                     |
| -------------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------- | ------------------------------- | -------------------------------- |
| **Local — Gemini Nano**    | Chrome built-in AI (Proofreader API, else Prompt API)                                          | 0                                 | **no**                          | Chrome on capable PCs; not Brave |
| **API — route `realtime`** | worker → Gemini/OpenAI with the user's key (V5.7 routes; e.g. GPT-5 nano or Gemini Flash-Lite) | ≈ 1–7 $/month for 3,000 words/day | **yes, every checked sentence** | everywhere                       |

- Mode **Auto** (recommended): local when available, otherwise nothing,
  with a message offering API mode.
- API mode is **off by default** and turned on only after a clear warning
  ("everything you type in checked fields is sent to <provider>").

### 1.4 Non-goals

- No automatic correction (never replaces without a click).
- No rewrite/translate/summary in real time (they stay on-demand, V5).
- No checking in password, email, phone, URL, number, search, OTP/card
  fields (V5.2 exclusion rules), nor in code editors (Monaco, CodeMirror,
  Ace), nor inside Correctly's own UI.
- No modification of the page DOM structure: underlines are an **overlay**
  (closed shadow root), never spans inserted into the editor.
- No server of our own; no new provider.

### 1.5 Required examples

| Situation                                                | Expected                                                                                                    |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Type "Je suis aller a Lyon." in a textarea, local engine | "aller" (grammar) and "a" (spelling) underlined; 0 network request                                          |
| Hover "aller" → Replace "allé"                           | exactly that word replaced, caret kept, Undo (Ctrl+Z) still works where the field supports it               |
| Keep typing in the sentence while a check runs           | old result dropped (text changed), sentence rechecked after the pause                                       |
| "les chat mange"                                         | "chat" and "mange" flagged (needs the whole sentence)                                                       |
| Ignore "Correctly"                                       | never underlined again in this page; Add to dictionary → never anywhere                                     |
| Password field                                           | nothing checked, nothing sent                                                                               |
| Brave, Auto mode                                         | no local engine → banner "real-time correction needs Chrome's built-in AI or API mode"; nothing sent        |
| API mode, 3,000 words typed                              | ≈ 200 requests counted under the new task `realtime` and its own limits                                     |
| Limit reached in API mode                                | checking pauses silently with a small badge; on-demand actions unaffected unless the total limit is reached |
| Gmail compose (contenteditable)                          | underlines positioned on the words; Replace works on simple text nodes, else "Copy suggestion"              |

## 4. Architecture

```text
page field ──typing──► smart.js (detect sentence, debounce, overlay UI)
                          │
             ┌────────────┴─────────────┐
     local engine                 API engine (opt-in)
 (Gemini Nano, in the context    sendMessage(CHECK_TEXT) ──► worker ──► provider
  chosen by the WP0 spike)                                   (route `realtime`, limits)
```

- **Page script** (`smart.js`, opt-in setting `triggers.realtime`): listens
  to `input`/`compositionend` in eligible fields, splits sentences
  (`Intl.Segmenter` granularity `sentence`), debounces, keeps a cache
  `hash(sentence) → issues`, at most **one check in flight per field**
  (an older one is aborted/ignored when the text changes).
- **Local engine**: Proofreader API when present (returns corrections with
  offsets), otherwise Prompt API with a fixed JSON schema. Runs in the
  context validated by the spike; if it must be an offscreen document, add
  the `offscreen` permission (audited).
- **API engine**: new message `correctly.v5.checkText` →
  `{ text, context }` (exact-shape guard, ≤ 1,000 code points), answered
  with `{ ok, issues[] }`. The worker uses route slot `realtime`, task kind
  `realtime` (own limits and statistics), short timeout (8 s), **no retry**,
  low output budget, minimal reasoning.
- **Result contract** (both engines): `issues: { start, end, original,
suggestions: string[] (1–3), kind: 'spelling' | 'grammar' }[]`; validated
  against the sentence snapshot (`text.slice(start, end) === original`),
  bounded (≤ 20 issues per sentence); anything else dropped. Model text is
  displayed as text only.
- **Overlay**: closed shadow root host, positioned from
  `Range.getClientRects()` (contenteditable) or a mirror element
  (textarea/input); repositioned on scroll/resize/input
  (`requestAnimationFrame`, passive listeners); removed when the field
  loses the text or the page navigates.
- **Replace**: re-reads the field, checks the range still holds
  `original`, then replaces through the existing V5 path (input events
  fired so the site sees the change); otherwise "outdated" and recheck.
- **Ignore / dictionary**: ignore = this page session; dictionary =
  `correctly.v5.dictionary` (≤ 2,000 words, settings page writes, page
  script reads through `PAGE_CONFIG`).

## 5. Data model and storage

- `correctly.v5.settings.triggers.realtime: boolean` (default false, not
  synced: needs site access per computer).
- `correctly.v5.settings.realtime`: `{ engine: 'auto' | 'local' | 'api',
apiConsent: boolean, disabledSites: string[] (hostnames, ≤ 200) }`,
  normalized; `apiConsent` true only after the warning dialog.
- `correctly.v5.dictionary`: `{ words: string[] }` normalized (trimmed,
  unique, ≤ 64 chars each).
- Providers: new route slot `realtime` (inherits Default unless set).
- Quota/stats: new task kind `realtime` (IndexedDB schema bump if needed,
  with migration and tests).

## 6. Security and privacy

- Local mode: **no network request at all** for checking (test).
- API mode: only the current sentence + one previous sentence; never the
  whole field, never the URL or page title; never from excluded fields.
- Same sensitive-field exclusions as V5.2 + `autocomplete` hints +
  `aria-hidden`/`inert`/disabled/read-only fields.
- Disabled per site (list) and on `chrome://`, Web Store, file viewers.
- No log; no text kept after the page closes (cache in memory only).
- Permissions: no new host; maybe `offscreen` (spike). All-sites access
  stays optional and asked when the feature is enabled.

## 7. Limits, statistics and costs

- API mode: each check = one request under task `realtime`; default daily
  limit for `realtime` (e.g. 500/day) set on enable; pause on limit.
- Estimated cost for 3,000 words/day (≈ 200 checks/day): GPT-5 nano
  ≈ 1 $/month; Gemini 3.1 Flash-Lite ≈ 5 $/month (reasoning tokens can
  double it). Local: 0.
- Statistics show `realtime` separately.

## 8. User interface (fr/en)

- Settings → **Real-time correction** (new page): switch (asks all-sites
  access), engine (Auto / Local / API with warning dialog), local engine
  status ("ready", "downloading 45 %", "not available on this browser"),
  disabled sites, personal dictionary (add/remove/export).
- In page: underlines, hover/focus card (Replace, Ignore, Add to
  dictionary), small badge near the field when paused (limit, offline,
  engine unavailable). Keyboard: Alt+Shift+↓ jumps to the next mistake,
  Enter replaces, Esc closes the card.
- Light/dark aware, high-contrast underlines, never covering the caret.
- All strings in `content/messages.ts` / `options/messages.ts` (fr/en);
  static texts via `scripts/i18n-options.mjs`.

| ---------------------------------------------- | ----------------------------------------------------------------- |
| Gemini Nano weak in French or unavailable      | WP0 spike first; API fallback; owner re-decides D1                |
