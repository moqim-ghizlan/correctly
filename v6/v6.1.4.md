  offering API mode (Brave case).
- **Rest of WP5:** engine status in settings ("ready", "downloading 45 %",
  "not available on this browser"), **Ignore** (page session), **Add to

  settings page, read by the page script through `PAGE_CONFIG`), disabled
  sites list (≤ 200), dictionary add/remove/export, pause badge near the
  field (limit, offline, engine unavailable) (R9).

  manual checklist on Gmail, WhatsApp Web, LinkedIn, Discord and a plain
  textarea; Chrome (local) and Brave (API); dark mode; no typing lag on a

- **Release (major, per `docs/general/processus.md`):** version, ZIP package,
